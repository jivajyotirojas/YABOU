# 「1手番＝1/4月」化に向けた、月・年に依る決まりの棚卸し

対象：`/home/user/YABOU/sengoku_spec.md`（8,731 行。§22.1「1ターン＝1か月」が現行）
目的：手番を「ひと月」から「月の四分の一」（4手番で1か月）へ変えるとき、意味が変わる決まりをすべて列挙し、扱いの候補を付ける。仕様書は変えていない。

凡例（右端の列）
- **×4**：月で数えていた数を手番の数に直す（1か月＝4手番。例：支城12か月→48手番）
- **月で数え直す**：決まりは月のまま残し、月替わり（4手番に1度）にだけ走らせる。数値は触らない
- **そのまま**：手番の長さに依らないので変えない（暦の月番号・年・季節で決まるもの、出来事ごとのもの）
- **要判断**：どちらにも寄せられ、遊びの手ざわりが変わる。決めが要る

## 12. まとめ ── 決めの要る順

1. **二つの時計**（0-1）：月替わりにまとめて走らせるもの（§3・§5 の大半、§2 の全部）と、手番ごとに走らせるもの（§4・§6・§7）を振り分ける。これで表の「月で数え直す」は数値を触らずに済む。
2. **移動力**（0-5）：手番あたりの歩き代と「一歩」の決まり。§6 の全行と §4 の「6か月のうちに着ける」に効く。
3. **戦の頻度**（0-6）：攻城・野戦を手番ごとに許すか、「着いた月」「次の月」を4手番に読むか。§7 の全行に効く。
4. **期間の単位**（§4）：`left` を手番で持つか月で持つか。どちらでも同じ長さにできるが、表示（§24.6 の切り上げ、§10.19.3 の「あと何か月」）と雪の半減の書き方が変わる。
5. **月ごとの籤**（0-4）：一揆・裏切り・病没・仕官・商人の移りを月1回のままにするか。
6. **暦データと表示**（0-7・§9）：手番の位の欄、鍵、札の表記、間合い。
7. **文言**（§10）：「月」を「手番」に読み替える箇所の一括直し。
8. ついでに **開墾地の穫れの食い違い**（0-10）を一か所に寄せる。
